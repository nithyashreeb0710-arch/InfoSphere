# InfoSphere
An interactive encyclopedia search website built using HTML, CSS, JavaScript and the Wikipedia API.
# InfoSphere – Explore Knowledge

**Discover. Explore. Learn.**

InfoSphere is an encyclopedia search website inspired by Wikipedia. It allows users to search for topics and explore relevant information through a simple and user-friendly interface.

## Features

- Search for information on different topics.
- Fetch search results using the Wikipedia API.
- Display article titles, links and information snippets.
- Display error messages for empty or invalid searches.
- Clean and responsive user interface.
- Cream-coloured background and educational globe design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Wikipedia API

## How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Open the `html` folder.
4. Run `index.html` using the Live Server extension.
5. Enter a search term and explore the results.

## API Integration

InfoSphere uses the Wikipedia Search API to retrieve relevant search results, including article titles, page links and snippets.
